# САПР базовой основы плечевого изделия 1:1

Интерактивный конструктор выкроек прямо в браузере на основе методики конструирования **ЦНИИШП / ЕМКО**. Позволяет строить параметрические лекала женского плечевого изделия (платья, блузы) с нагрудной, плечевой и талиевыми вытачками, а также согласованного втачного анатомического рукава с выводом на домашнюю печать на листах формата **А4 в масштабе 1:1**.

![Скриншот интерфейса](https://raw.githubusercontent.com/Maksre1/lekalo/main/screenshot.png)

## Основные возможности

- **Параметрическое построение по индивидуальным меркам:**
  - Обхваты: груди (Ог), талии (От), бедер (Об), шеи (Ош), длина плеча (Шп).
  - Высоты и баланс: длина спинки (Дтс), длина переда (Дтп), высота груди (Вг), центр груди (Цг), высота бедер (Вб), общая длина изделия (Ди).
  - Рукав: обхват плеча/бицепса (Оп), длина рукава (Др), ширина внизу (Оз).
- **Типовые размеры ГОСТ:** Быстрое переключение стандартных размеров (42, 44, 46, 48, 50, 52, 54) в один клик.
- **Учёт типа осанки:**
  - *Обычная (условно-пропорциональная)*;
  - *Сутулая* (удлинение спинки, увеличение раствора плечевой вытачки для лопаток);
  - *Прямая / перегибистая* (удлинение переда, уменьшение плечевой вытачки спинки).
- **Степени прилегания силуэта:** Пресеты прибавок (*Облегающий*, *Умеренный*, *Свободный*) и тонкая ручная настройка прибавок по груди, талии, бедрам и глубине проймы.
- **Моделирование фасонов:**
  - *Перевод нагрудной вытачки:* в плечевой шов (базовая основа), в боковой шов (французская вытачка под проймой), в талию (приталенный силуэт без плечевого шва), в пройму (элегантный рельеф).
  - *Формы выреза горловины:* круглая, V-образная, лодочка (расширение по плечу), прямоугольное каре + ползунок плавного углубления выреза (0..8 см).
  - *Вариации рукава:* классический длинный (Др), укороченный 3/4 (~72% длины), летний короткий (22 см).
  - *Силуэт изделия:* базовый прямой / приталенный или летящий клеш / трапеция (+5.5 см к низу со скруглением бокового шва).
- **Индикатор прилегания и тепловая карта (Heatmap):**
  - Оценка посадки по 4 анатомическим поясам (грудь, талия, бедра, рукав).
  - Классификация силуэта: *Облегающий (бодикон)*, *Прилегающий*, *Полуприлегающий (ГОСТ)*, *Свободный*, *Оверсайз*.
  - Наглядная цветная проекция зон свободы прямо на чертеже лекал.
- **Калькулятор расхода ткани и раскладка:**
  - Расчет точного метража ткани для покупки с учетом ширины рулона (110 см, 140 см, 150 см).
  - Режимы раскроя: раскладка «в сгиб» (вдвое) со строгим совмещением спинки с линией сгиба или «в разворот» (в один слой).
  - Учет запаса на декотирование и усадку при ВТО (0..15%).
  - Интерактивная SVG-схема раскладки на полотне ткани с долевыми стрелками, линейкой расхода и расчетом коэффициента эффективности раскроя (%).
- **Проверка сопряжения рукава и проймы:** Аналитический расчёт длины кривых проймы и оката рукава методом численного интегрирования кривых Безье, контроль посадки оката (+2.0 … +3.8 см).
- **Печать на листах А4 (PDF 1:1):**
  - Автоматическая нарезка лекал на страницы формата А4 с рамкой 180×267 мм (поля по 15 мм).
  - Метки совмещения (ромбики и кресты), буквенно-цифровая сетка листов (A1, A2, B1...), колонтитулы с параметрами.
  - Проверочный тестовый квадрат со шкалой для сверки масштаба печати (100%).
  - Пропуск пустых листов бумаги.
- **Экспорт в вектор (SVG 1:1) и растр (PNG):** Подетально для спинки, полочки, рукава или единого чертежа.
- **Адаптация под смартфоны:** Удобная навигация с переключением экранов («Параметры и мерки» / «Чертёж»), крупные шаговые кнопки `+` / `−` для пальцев и интерактивные подсказки к каждой мерке.

## Запуск

Проект работает локально в любом современном браузере без необходимости установки Node.js или бэкенд-сервера.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Maksre1/lekalo.git
   ```
2. Откройте `index.html` в браузере (двойным кликом или через любой локальный HTTP-сервер).

```
├── index.html            # Главная страница и 5-шаговый интерфейс САПР

│   ├── state.js          # Состояние, конфигурация фасонов, типовые параметры ГОСТ
│   ├── cad-geometry.js   # Математическое ядро построения геометрии ЕМКО/ЦНИИШП
│   ├── cad-renderer.js   # Генерация SVG-путей, интерактивный холст, тепловая карта
│   ├── fabric-layout.js  # Калькулятор расхода ткани и интерактивная схема раскладки
│   ├── export-pdf.js     # Нарезка на листы А4 в PDF (jsPDF), экспорт SVG/PNG
│   └── ui.js             # Логика вкладок, шагов, модальных окон и подсказок
└── .gitignore
```
